Praxis is the foundation and component layer every EHSQ Enterprise surface is built on: tokens, application chrome, and the record-form system, as plain stylesheets and vanilla scripts. There is nothing to compile and nothing to import at runtime. A single <link> and two attributes on <body> is the whole integration.

Every example on this site is real Praxis running in its own frame, loading the same dist/ that npm install gives you. The tables are measured from src/ at build time. Nothing here is transcribed by hand, which is the only way a reference stays true to the thing it describes.

Alpha, and so is this site. Praxis is at {{version}} and is not production-ready. Class names, token names and markup structure are all still moving, and pre-1.0 releases contain breaking changes without a deprecation cycle. Pin the exact version — @{{version}}, never @0.1, ^{{version}} or @latest.

This site is built from main, not from a release. It redeploys on every push, from that commit's src/, so when main is ahead of the latest tag it documents code you cannot install yet. The version in the header above is the one these pages describe — check it against the version you have pinned. There is no archive, so there is no way to read the docs for an older release.

Where it is thin. Every class family in src/ is named on some page, but that is coverage of the vocabulary rather than depth: the live examples show each component's markup contract, not every variant and state. Some things cannot be demonstrated at all — the Mazlan drawer ships its CSS without its markup, so fifteen of its class families are an inventory with no working example. Pages get added, rewritten and renamed without notice.

Treat it as the most accurate description of Praxis that exists, not as a specification. The full statement is in the README.

Fonts

Praxis sets font-family: 'Gilroy' and ships no font files — Gilroy is licensed and cannot be redistributed. The build strips the @font-face blocks and emits praxis-fonts.example.css showing how to point the same family at your own licensed copy. Without it you get the fallback stack, which is 'Segoe UI' then Roboto then Helvetica Neue then Arial. The layout is unaffected; only the letterforms change.
