Praxis is the foundation and component layer every EHSQ Enterprise surface is built on: tokens, application chrome, and the record-form system, as plain stylesheets and vanilla scripts. There is nothing to compile and nothing to import at runtime. A single <link> and two attributes on <body> is the whole integration.

Every example on this site is real Praxis running in its own frame, loading the same dist/ that npm install gives you. The tables are measured from src/ at build time. Nothing here is transcribed by hand, which is the only way a reference stays true to the thing it describes.

Fonts

Praxis sets font-family: 'Gilroy' and ships no font files — Gilroy is licensed and cannot be redistributed. The build strips the @font-face blocks and emits praxis-fonts.example.css showing how to point the same family at your own licensed copy. Without it you get the fallback stack, which is 'Segoe UI' then Roboto then Helvetica Neue then Arial. The layout is unaffected; only the letterforms change.
