Every value on this page is read from a live document, once per theme, rather than copied out of the stylesheet. That distinction matters here more than anywhere else in Praxis: several colour tokens are declared one way in praxis-tokens.css and overridden under the Praxis variant, so the token file is not the answer to "what colour is this".

Tone pairs

The paired background and foreground used by status chips and badges. Always use the pair, never one half — the foregrounds are literals rather than palette references on dark, because the palette's 70 steps are tuned for light surfaces and go muddy.

Two live traps

Never substitute one token for another by name. Check the resolved value in both themes first. --t-sm looks like it maps to --praxis-type-size-sm, but its fallback actually resolved to type-size-base. --r-lg is 1rem against a canonical 16px — equal only because nothing overrides the root font size. The resolved columns on this page exist so you do not have to take a name on trust.

Interactive teal is a light colour in dark mode. --praxis-color-interactive-default becomes #29D2D7, luminance .55. White text on it as a fill measures 1.86:1 against a 4.5 minimum. Use --px-primary-fg (dark ink, 12.4:1) whenever that colour is a fill. Praxis already does this for the calls to action it defines; if you invent a filled cyan control, it is on you.

Two more, worth knowing before you go hunting:

  • --praxis-radius-card is 20px in the token file and 12px under Praxis. The override is the one that renders. 12px is the card geometry.
  • Most --praxis-* and --px-* tokens are redefined per theme. Only --praxis-color-white and the palette primitives resolve identically everywhere — and as the swatches above show, not even all of those.
