Three copies, no component. .cf-empty (praxis-filters.css), .admin-table__empty (praxis-admin.css) and .tb-dropdown__empty (praxis-controls.css) each solve this locally. Tier 1 on ROADMAP.md.

Three independent definitions of the same idea in three sheets is exactly the signal that preceded the four controls promoted in 0.1.9 — a toolbar menu, an icon button, a filter field and a toast, each hand-copied into up to twelve pages in versions that had drifted apart. This is the same shape of problem caught earlier.

It also matters more here than in most products. An empty list in an EHS application is usually good news — no open findings, no overdue actions — and an empty state that reads as a failure ("No data") tells the user the wrong thing about their own site.

Anatomy

  1. Glyph — optional, muted, large. Not an illustration; Praxis ships no illustrations and should not start.
  2. Headline — states the situation in the user's terms.
  3. Body — one sentence, why it is empty or what to do.
  4. Action — optional, one button.

Variants

VariantSituationTone
--first-runNothing has been created yetInviting, with an action. "No permits yet — create the first one"
--clearThere is genuinely nothing, and that is the desired statePositive, no action. "No overdue actions". This is the variant general design systems do not have and this domain needs
--no-resultsA filter or search excluded everythingNeutral, with a clear-filters action. What .cf-empty does today
--errorThe data could not be loadedNot an empty state. Belongs to alert or an inline banner — worth naming here so it does not get folded in

Open decision: two sizes or one. An empty state inside a .tb-dropdown is a single line of text; one filling a table body has room for a glyph and an action. --inline and the default is probably the answer, rather than one component stretched across both.

States

None. An empty state is a state.

Usage guidelines

Do

  • Say what is true in the user's terms. "No overdue actions", not "No data".
  • Give an action only where there is one worth taking.
  • Distinguish "nothing yet" from "nothing matching" — they need different words and different actions.

Don't

  • Use an error tone for a legitimately empty list.
  • Add an illustration. Praxis ships no illustration set and one page's cartoon becomes everyone's maintenance.
  • Leave the container blank. A table body with nothing in it reads as a loading failure.

Accessibility

  • The headline is text, not an image or a glyph.
  • The glyph is aria-hidden.
  • An empty state arriving after a filter change is a content change and needs announcing; arriving on first paint does not.
  • Contrast: --praxis-color-text-tertiary is #616f7e and must be checked against whatever surface the empty state lands on. Inside a --px-surface-2 panel it is tighter than on white.
