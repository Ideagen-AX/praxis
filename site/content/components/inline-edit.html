Changing one field on forty rows should not mean forty round trips through a record page. Praxis has .rfield--locked for a read-only field and no path from read-only to editable in place.

Anatomy

Not designed yet.

Variants

Text, select, and date. In a table cell versus in a record field — the two need different affordances, because a table cell cannot afford a visible edit button per row.

States

Read / hover (the affordance appears) / editing / saving / saved / failed. Failed must keep the entered value and say what happened; an inline edit that silently reverts is worse than no inline edit.

Markup contract

A real button in read mode, so the control is reachable and announced as editable. On activation, focus moves into the input; Escape cancels and restores; Enter commits. The change must be announced. Whether saving is optimistic is an application decision the component must not assume — in a regulated record it usually should not be.

Accessibility

Hover-only affordance is not discoverable by keyboard, so read mode must be focusable and named ("Edit severity"). Announce the outcome. Do not trap focus in the field after commit.
