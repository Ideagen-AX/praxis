A risk score, a severity band, a confidence level. Praxis styles the bare checkbox and the bare radio is already an acknowledged asymmetry; input[type="range"] is a third unstyled native control.

Anatomy

Not designed yet.

Variants

Single value; two-thumb range (APG lists Slider (Multi-Thumb) separately, and it is materially harder); stepped with tick labels. A risk matrix is arguably not a slider at all — it is a grid of named cells — which is worth resolving before building this.

States

Rest, hover, dragging, focused, disabled. The value must be visible as text at all times; a slider whose value is only its thumb position is unusable for anything precise.
