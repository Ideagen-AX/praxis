Markup contract

A real <kbd> element, one per key, nested for a chord as the HTML spec describes. The platform difference matters: Ctrl on Windows and Linux, ⌘ on macOS, and picking the wrong one makes the hint actively wrong.

Token reference

--px-chip fill, --praxis-radius-sm, --praxis-type-size-2xs. Praxis ships no monospace stack — a keyboard hint arguably wants one, and that would be a new token.

Figma adaptation

Not mapped. Praxis has no Figma library.

Usage guidelines

Not written yet.

Accessibility

A hint, not a control. Where it sits beside a menu item the shortcut should be in the item's accessible name so it is announced once, rather than being a separate node the user has to hear.

Dimensions

Proposed: 18px min height, 4px 5px padding, 11px text.
