Mazlan is not this. praxis-mazlan.css is an AI conversation drawer; a comment thread is human annotation attached to a record, and none of it is defined. Tier 2 on ROADMAP.md.

Investigations are collaborative and the collaboration is part of the record. A supervisor questions a root cause, a safety lead attaches context, a contractor is asked to confirm a detail. That discussion has to live on the record and, in a regulated system, it is usually disclosable — which makes the internal-versus-external distinction below a compliance feature rather than a convenience.

Anatomy

  1. Composer — a textarea, an attach button, a submit.
  2. Comment — avatar, author, timestamp, body.
  3. Visibility marker — internal or visible to the contractor. See Variants.
  4. Reply — one level of nesting, no more.
  5. Edited marker — with the original preserved. This is a regulated record.

Variants

VariantUse
ThreadFlat, chronological. The default
--internalVisible only inside the organisation. Needs an unmistakable treatment — a tinted surface and a label, not a small icon
--resolvedA question that has been answered and can collapse
--pinnedHeld at the top. Useful, and it breaks chronology, so it must be visibly separated

The decision that matters: internal comments must be impossible to post by accident. Getting that wrong discloses an internal opinion to a contractor or, worse, withholds something that should have been shared. A quiet toggle is not enough; the composer should change appearance while internal mode is active.

States

  • Empty thread — empty state, inviting tone.
  • Composing / submitting / failed. A failed comment must keep its text.
  • Edited — marked, with the original reachable.
  • Deleted — the tombstone stays. "Comment removed by M. Silva, 14 Mar" is the correct rendering; removing the row is not.
  • Unread — since the reader last opened the record.

Responsive behavior

Desktop: composer at the top or bottom consistently, thread beneath. Phone: composer collapses to a single line that expands on focus, so the thread is not pushed off screen.

Usage guidelines

Do

  • Make internal mode visible in the composer while it is active.
  • Keep edited and deleted comments accounted for.
  • Use absolute timestamps.

Don't

  • Nest replies more than one level.
  • Submit on Enter.
  • Remove a deleted comment from the thread — leave the tombstone.
  • Use this for AI conversation. That is Mazlan.

Accessibility

  • Each comment an <article>, so a screen reader can move between them.
  • Visibility in text.
  • Incoming comments announced politely, not assertively — a thread that interrupts on every arrival is unusable.
  • The composer's textarea has a real label, even when the visible label is only a placeholder.
